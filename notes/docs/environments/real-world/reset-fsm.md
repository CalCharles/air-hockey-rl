# Reset policy FSM

Finite state machine that resets the puck from the bottom of the table between policy episodes on the real UR5.

Primary code: [`ResetPolicyFSM`](../../../../scripts/real/rollout_reset_policy_real.py) class.
Collector integration: [`real_collector_reset.py`](../../../../scripts/td3/helper/real_collector_reset.py).

## Five phases

### Phase 1: `goto_start`

Move the paddle to the starting corner of the bottom edge loop path. The paddle navigates to a waypoint near the bottom-left or bottom-right of the table (randomized). Completes when the paddle is within `goto_start_arrive_m` (default 0.05 m) of the target position.

### Phase 2: `edge_loop`

Sweep the paddle along the bottom boundary from one side to the other. The path follows a series of waypoints generated by `_build_edge_loop_path`, offset from the wall by `off_wall_abs_y_m` (default 0.35 m). Each waypoint advances when the paddle is within `waypoint_advance_m` (default 0.05 m). The loop can repeat up to `max_stage2_cycles` (default 5) if the puck is not successfully pushed toward center.

### Phase 3: `upward_burst`

Execute a rapid upward flick (negative x direction) for `burst_steps` (default 5). The action magnitude is `burst_action_m` (default 0.2 m). This kicks the puck away from the bottom wall toward the playing area.

### Phase 4: `wait_for_puck`

Hold position and wait for the puck to fall within `puck_proximity_m` (default 0.5 m) of the paddle. A `post_upward_check_steps` (default 20) delay is enforced after the burst before checking proximity, giving the puck time to settle.

### Phase 5: `strike`

Execute a ramping upward strike sequence with increasing action magnitudes: `[-0.3, -0.6, -1.0, -1.0, -1.0]`. This sends the puck decisively into the playing area for the next policy episode.

## When reset runs

The collector decides between two reset paths at episode end:

1. **`ResetPolicyFSM`** -- used when the puck is near the bottom of the table and a learned or scripted reset can recover it. Triggered by `_should_run_reset_policy_at_episode_start`.
2. **`hard_reset_with_pause`** -- manual pause for human intervention when the puck is in an unrecoverable position or after safety events. The program pauses and waits for operator input.

## Collector integration

**Code:** [`real_collector_reset.py`](../../../../scripts/td3/helper/real_collector_reset.py)

After the reset FSM completes:

1. `merge_reset_fsm_artifact_into_pending` buffers the reset episode's metadata (episode ID, partition label, step count, done reason) for later artifact output.
2. `soft_reset_prime_paddle_and_extract_previous_puck` calls `env.soft_reset()`, primes the paddle position history with stand-still observations (so the temporal motion window starts clean), and extracts the puck position for primitive exploration state.
3. The collector re-enters the policy loop with a transition hold period to smooth the handoff.

## `ResetPolicyFSM` parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `loop_max_delta_m` | 0.1 | Max action step size during edge loop |
| `burst_action_m` | 0.2 | Upward burst action magnitude |
| `burst_steps` | 5 | Number of burst action steps |
| `goto_start_arrive_m` | 0.05 | Arrival tolerance for phase 1 |
| `waypoint_advance_m` | 0.05 | Waypoint advance tolerance for phase 2 |
| `puck_proximity_m` | 0.5 | Puck distance threshold for phase 4 |
| `post_upward_check_steps` | 20 | Steps to wait after burst before checking puck |
| `shared_success_threshold_proportion_from_bottom` | 0.5 | Where to draw the success line on the table |
| `off_wall_abs_y_m` | 0.35 | Offset from wall for edge loop path |
| `min_off_wall_window_steps` | 5 | Minimum steps in off-wall segment |
| `max_stage2_cycles` | 5 | Maximum edge loop repetitions |
