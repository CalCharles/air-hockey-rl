## Rendering teleop trajectories by frame intervals

Teleop trajectories (split-schema HDF5 from `scripts/real/teleoperate.py`) can be
chopped into fixed-length segments and rendered as GIFs using the
`render_teleop_segments.py` script.

### Steps

1. **Record a teleop trajectory** (if not already done):

```bash
conda activate air
python scripts/real/teleoperate.py \
    --cfg configs/real_configs/mouse_config.yaml \
    --save-path sysid/teleop
```

Press `y` to save each trajectory. Files land as `sysid/teleop/trajectory_dataN.hdf5`.

2. **Render segments** (100-frame intervals by default):

```bash
PYTHONPATH=/home/pearl/air-hockey-rl \
python scripts/smooth_policy/visualize_demo/render_teleop_segments.py \
    sysid/teleop/trajectory_dataN.hdf5 \
    -o sysid/teleop/trajectory_dataN_segments \
    --interval 100
```

Replace `N` with the trajectory number (0, 1, 2, …).

The `PYTHONPATH=...` prefix is needed to avoid the ROS `scripts` package shadowing
the repo's `scripts/` directory.

3. **Browse results.** Each segment directory contains:
   - `segment_START_END.hdf5` — sliced HDF5
   - `trajectory_visualization.gif` — rendered GIF with frame numbers overlaid

Output tree example:

```
sysid/teleop/trajectory_data1_segments/
├── frames_0_100/
│   ├── segment_0_100.hdf5
│   └── trajectory_visualization.gif
├── frames_100_200/
│   ├── segment_100_200.hdf5
│   └── trajectory_visualization.gif
...
└── frames_3500_3527/
    ├── segment_3500_3527.hdf5
    └── trajectory_visualization.gif
```

### Script location

`scripts/smooth_policy/visualize_demo/render_teleop_segments.py`

### Options

| Flag | Default | Description |
|------|---------|-------------|
| `input` | (required) | Path to split-schema HDF5 |
| `-o` / `--output-dir` | `<stem>_segments` next to input | Output root directory |
| `--interval` | `100` | Frames per segment |
